# MGC Building Ltd

Static website for MGC Building Ltd, builders based at 52 Greycote, Shortstown, Bedford, MK42 0TU.

The site is built with Astro. Pages are pre-rendered. There is no tracking script.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

The production site URL in canonical tags, the sitemap and `robots.txt` is `https://www.mgcbuilding.com`.

## What is on the site

- Home, about, services, individual service pages, project photos, reviews, areas, contact, privacy and cookies
- Local pages for the towns they are asked about across the five counties named on their previous site
- `sitemap-index.xml` from the Astro sitemap integration
- `robots.txt`, Open Graph tags, and JSON-LD for the business, services, breadcrumbs and the home-page questions
- Google reviews are quoted in full, including the 2-star review. The Google score is not marked up as review schema, because those reviews were not collected on this site

Project photos are the firm’s own job photos, including the gallery published on their Bark profile. Optimised WebP copies live in `public/images/work`.
